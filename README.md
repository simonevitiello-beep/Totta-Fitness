# Totta Fitness

Tracker di allenamento di Carlotta. PWA in HTML/JS puro, dati solo sul telefono.

Pubblicata con GitHub Pages: https://simonevitiello-beep.github.io/totta-fitness/

A ogni pubblicazione alzare `CACHE` in `service-worker.js` (totta-v1, v2...): fa comparire "Aggiorna ora" sul telefono.
